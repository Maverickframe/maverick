## Предложения в базу знаний
- [target: CLAUDE.md §6 Conventions | new] [durable] Стандартная ширина контента нового дизайна — `.container container_small` (`--container-small`: 1440px на десктопе = поля 240px на макете 1920 в Figma), а не широкий `.container` (`--container`: 1720px). Большинство new-design блоков уже на `container_small` (hero-front, trusted, performance-scale, faq, selective-works, why-choose-us); на широком `.container` сидят cta, similar-cases, marketing-sales, workflow, our-work — при сборке секций по Figma выравнивай их левый край на `container_small`.
- [target: CLAUDE.md §4 Layout | new] [durable] Хлебные крошки — общий партиал `components/new-design/breadcrumbs.php`: вызывается `get_template_part('components/new-design/breadcrumbs', null, ['breadcrumbs' => [['link'=>…, 'name'=>…], …]])`, текущая страница (`get_the_title()`) дописывается последним пунктом автоматически. Стили крошек рассчитаны на ТЁМНЫЙ hero (бледный light-grey + reveal-fade), поэтому на БЕЛОМ hero их надо переопределить: `opacity:1`, тёмные ссылки, серый текущий пункт, чёрный шеврон (`arrow-right-breadcrumbs-black.svg`).
- [target: CLAUDE.md §7 Gotchas | new] [durable] Подсветка заголовка: `<em class="mark">` внутри `.hero__title` — это белый текст, проявляемый accent-заливкой через `background-size`. Если reveal-анимация не отрабатывает, фраза остаётся white-on-white и исчезает. Гарантия видимости: `.hero__title em.mark { background-size: 100% 100% !important; }`.
- [target: CLAUDE.md §7 Gotchas | new] [durable] `header.php` формирует html-класс страницы как `str_replace('.php', '', get_page_template_slug())`, поэтому страница на шаблоне `templates/template-X.php` получает html-класс `templates/template-X` (СО СЛЕШЕМ). В CSS таргетируй такие страницы через `[class*="template-X"]`, а не `.template-X`.
- [target: CLAUDE.md §6 Conventions | new] [durable] Новый ACF-блок: каталог `components/blocks/<name>/` с `block.json` (`name: acf/<name>`, `acf.renderTemplate: <name>.php`, `acf.mode: preview`) + php-шаблон + scss (авто-регистрация через `register_block_type(dirname(...))` в functions.php). SCSS блока надо импортировать в ДВА бандла: `src/scss/bundles/blocks-frontend.scss` (фронт) и `src/scss/blocks.scss` (редактор). Фронт-бандл `src/scss/bundles/front.scss` = `base.scss` + `blocks-frontend.scss`.
- [target: CLAUDE.md §6 Conventions | new] [durable] Чтобы на странице грузились стили нового дизайна (ACF-блоки), её шаблон должен попасть в `isNewDesign()` (functions.php) — иначе грузится legacy `main.scss` и блоки рендерятся без стилей. Конкретный SCSS-бандл per-template определяется `mfs_page_bundle_key()` (inc.vite.php), дефолт — `front.scss`.
- [target: CLAUDE.md §5 Tech stack | new] [durable] Слайдеры на сайте — Splide (`@splidejs/splide` + расширение AutoScroll), инициализация в `src/js/components/sliders.js`. Бесконечная лента в обе стороны (маркиза): опции `type:'loop'`, `drag:'free'` (или `true`), `autoScroll:{ speed, pauseOnHover }`, монтаж `splide.mount({ AutoScroll })`. Разметка обязательна: `.splide > .splide__track > ul.splide__list > li.splide__slide`. Splide core CSS подключён через `src/scss/new/common/slider.scss` (внутри `base.scss`), т.е. уже доступен во фронт-бандле.
- [target: CLAUDE.md §12 Block patterns | new] [durable] Блок `performance-scale` выводит шапку (`.performance-scale__info` с subtitle/h2) только если subtitle ИЛИ title непустые — его можно использовать как «голую» полосу статистики без заголовка (в Figma секция статистики на Solutions идёт без шапки).
