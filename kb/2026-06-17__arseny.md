## Предложения в базу знаний
- [target: skill:maverickframe-publish §Common errors | durable] cli/run `post meta update` (`/wp-json/wpvibe/v1/cli/run`) СРЕЗАЕТ HTML-теги (`<span>`, `<em>`) из значений — возвращает «успех», но сохраняет без тегов. Для ACF-полей с HTML (цифры с `<span>` для акцента, hero/H1 с `<em>`) ставить значение через ACF-редактор (Gutenberg → Save, отправляет форму metabox; админ с unfiltered_html сохраняет HTML) или post.php FormData. Plain-text — можно через cli. (дополняет память maverickframe-cli-strips-html)
- [target: skill:maverickframe-seo-analysis §Sitemap | durable] Per-CPT sitemap Rank Math на Rocket.net кэшируется крайне цепко: его НЕ пробивают `wp cache flush`, WP Rocket purge, CDN «Purge Everything», удаление опции `rank_math_sitemap_cache_files`, пересохранение настроек Sitemap и пересохранение поста. Запрос с залогиненной кукой не байпасит (значит это собственный кэш Rank Math, а не page/CDN-кэш; cf-cache-status=DYNAMIC). Симптом после смены базового слага CPT: один sub-sitemap застревает на старом слаге с замороженным `lastmod`, соседний — свежий. Если `get_permalink`/canonical уже правильные — это чисто кэш; лечится платформенным сбросом кэша в дашборде Rocket.net (object/all caches), не из WP.
- [target: new: multilingual.md | durable] Polylang фильтрует WP_Query по текущему языку. Для CPT, который существует только на EN (`team`; или success-stories, заданные EN-ID в `post__in`), на /es/ запрос вернёт 0 элементов. Чтобы выводить независимо от языка — добавить `'lang' => ''` в аргументы WP_Query (сделано в `components/new-design/team/team-members.php` и в фолбэке мега-меню).
- [target: new: multilingual.md | durable] Языковой переключатель строится на `pll_the_languages(['raw'=>1,'hide_if_no_translation'=>0])`: для каждого языка `url` = перевод ТЕКУЩЕЙ страницы (или главная языка, если перевода нет), `name` = «English»/«Español», флаг `current_lang`. Так сделан Apple-style свитчер в `components/common/footer.php` — работает на любых страницах/типах, EN+ES. Подпись = язык (English/Español), не страна.

- [target: CLAUDE.md §11 | durable] Rank Math SEO-балл занижен на шаблонных ACF-страницах (team и подобные), потому что Rank Math анализирует `post_content` редактора, а он пустой (контент рендерится из ACF/шаблона). Контентные проверки (длина, ключ в тексте, плотность, alt, ссылки) проваливаются → низкий балл это структурная особенность, не реальная проблема ранжирования. Реально поднимаются только базовые (focus в title/description/slug).
- [target: CLAUDE.md §6 | durable] Новое ACF-поле можно добавить без UI: вписать его определение в JSON группы в `acf-json/` и увеличить `modified` (epoch) → в Custom Fields → Field Groups появится «Sync available» → Sync импортирует поле в БД. На проде после деплоя изменённого acf-json группу тоже нужно один раз Sync, иначе поле не появится в редакторе.

- [target: CLAUDE.md §9 | durable] Git из песочника Cowork: read-операции (fetch/log/diff/status) проходят, но оставляют `.git/index.lock`, который песочник не может удалить, и не могут чистить `.git/objects` («Operation not permitted»). Все write-git (commit/merge/push/reset/force-push) делать в обычном терминале пользователя; если до этого был read из песочника — сначала `rm -f .git/index.lock`.
